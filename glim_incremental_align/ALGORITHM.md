# 多 session 增量建图 —— 方法说明

这份文档只讲**逻辑**：要解决什么问题、每一步在做什么、为什么这么选。
不涉及参数名、命令行、目录结构和编译——那些在 [README.md](README.md) 里。

---

## 1. 问题

同一片区域被采集了多趟（不同日期、不同路线、有时反向行驶）。每趟自带组合导航（INS）
给出的位姿，但那个位姿只有分米量级的精度，而且**每趟各错各的**。直接把各趟的点云按
INS 位姿叠在一起，同一根杆子、同一条车道线会出现两三份错开的副本——这就是"重影"。

目标：求一组新的位姿，使得所有趟叠在一起时肉眼看不出重影。

两个约束条件塑造了整个方案：

- **增量**。数据是一批批来的。来一趟新的，不能把之前所有趟重新算一遍——那样每次的成本
  随数据量线性增长，很快就跑不动了。
- **不能只让新数据单方面迁就旧数据**。两边各有误差时，正确解是各让一半。若把旧位姿钉死，
  新数据只能往错的位置上凑。

---

## 2. 数据模型与坐标系

一趟采集叫一个 **session**，它由若干 **clip**（连续录制的片段）组成，每个 clip 里是按
时间排列的**帧**：一帧点云 + 一份 INS 位姿 + 若干张相机图像。

clip 之间可能缺数据（抽出来的片段，彼此隔着几百米），所以"帧号连续"不等于"空间连续"。

三个位姿量必须分清：

| 量 | 含义 |
|---|---|
| `T_w_v` | 世界系下的**车体**位姿。这是待优化的量，也是 INS 直接给出的量 |
| `T_v_l` | **外参**：雷达相对车体的安装位姿。整车共享一个，标定给出初值 |
| `T_w_l` | 世界系下的**雷达**位姿 = `T_w_v · T_v_l`。点云变换用它 |

这个区分不是形式上的。所有配准测量都是**雷达系之间**的相对位姿，而优化变量是车体位姿，
两者靠外参联系。如果外参也参与优化，那么位姿和约束必须始终配套使用——把优化后的位姿
配上标定的原始外参，几何就会错一个外参变化量。

**世界系**是 UTM 投影的局部坐标：每个 clip 的标定文件里有一个 `utm_center`，位姿是相对
它的偏移。不同 session 的 `utm_center` 可能不同，所以加载后第一件事就是把所有 session
平移到同一个基准上，否则"按距离找邻域"会找到几百米外的地方。

---

## 3. 核心思路

把问题建成一张**位姿图**：

- **顶点** = 每一帧的车体位姿（几千到上万个）
- **边** = 两帧之间的相对位姿测量，来自点云配准
- 另有每个顶点一条**绝对先验**，来自 INS

然后最小化所有测量的加权残差。这是标准做法，方案的全部内容在于**边从哪来、权重怎么定、
以及增量怎么组织**。

一个贯穿全篇的观念：

> **配准精度的上限，是参照物自身的清晰度。**

如果拿来当 target 的那块点云自己就糊了 0.1 m，那无论怎么配，新帧也不可能对到 0.03 m。
这时如果测出来的最近邻距离反而更小，那不是配得更准，而是"往模糊里塞"——把源点塞进了
一团本来就散开的点里。所以每次拼出 target 之后都要先量它自己有多糊（把参与拼接的帧按
奇偶拆两半，互测最近邻），那个数就是这条约束的精度天花板。

## 4. 处理流程

### 4.1 加载与预处理

顺序是固定的，不能调换：

1. **统一世界系**——把各 session 平移到基准 session 的 `utm_center`
2. **范围过滤**（可选，小范围试跑用）——必须在统一世界系之后，否则同一个方框框到的
   是不同地方
3. **外参偏航修正**（可选）
4. **断连/静止块分析**

第 4 步值得单独说。用并查集把空间上挨着的帧连成连通域，判据有两条：

- 同一 clip 内**时序相邻的帧无条件相连**——那是一段连续录制，车在开，间距大只说明车快。
  少了这一条，正常轨迹会在每个稍快的路段被切断
- 真正的断开发生在 **clip 之间**（缺数据的地方）

得到连通域后，判据不是"域的大小"而是**域自身的空间尺度**：尺度接近零的块表示车在这里
根本没动过（比如停在起点扫了几十帧），这种块在图上就是脱离主路线的一坨，且拿不到有效的
帧间约束。而尺度几百米的块是真实路段，只是和主域之间缺了数据，不能同等对待。

分析默认**只报告不删数据**——判读需要的信息一条不少，但动不动数据由人决定。

### 4.2 每个待优化 session 的三个阶段

**阶段一：自身整段 BA。** 目的是把这一趟自己捋直。

分窗处理（窗口若干帧、窗口间 50% 重叠），因为全部帧的点云同时留在内存里是不可行的。
窗口内两两配准建立帧间约束，配合 INS 先验解一次。

同时**独立地**跑一路回环：同一个地点隔很久再经过时，两帧空间上挨着但落在不同窗口里，
分窗逻辑一条约束都建不出来。而这类"空间近、时序远"的帧对数量很大，涉及近半数的帧——
它们承载的是**全局形状的闭合**，不闭合的话，一条几公里的轨迹只靠 INS 先验维持形状，
重访同一地点时两次位姿必然差十几厘米，而这个误差没有任何约束去消除。

**阶段二：与已优化的 session 建约束。** 沿着"共位帧"（离已有地图足够近的帧）每隔一段
距离开一个区域，在区域内：

1. 取邻域内**所有已优化 session** 的帧，先做一次局部联合 BA，再拼成 target
2. 当前 session 的帧（可以取前后若干帧拼成一小段）逐个配到这个 target 上
3. 每条配准结果记成一条"当前帧 ↔ 最近参照帧"的相对位姿约束

第 1 步的联合 BA 有个必须处理的连带效应：它把几个已有 session 相对挪动了，target 因此
处在一个**新的局部规范系**里，而图里那些参照帧的位姿还是存档值。所以必须把 BA 产出的
跨 session 参照帧之间的相对位姿**也发成约束**，否则新建的边和图里的位姿不在同一个系里，
错量恰好是那几个 session 原本的不一致量。

**阶段三：自身约束 + 跨 session 约束一起解**，此时已优化的 session 暂时固定。

### 4.3 最终联合优化

所有 session 处理完后，把**全部位姿**放在一起解一次，只锚定一帧来定全局规范。

关键点：老 session 的**约束**从存档复用（不重新配准，那是几小时的成本），但它们的
**位姿参与优化**。这正是第 1 节说的"不能单方面迁就"——放开老位姿几乎不要钱（几万条边的
稀疏图解一次是秒级），真正的成本在配准。

### 4.4 存档

存档是增量的全部状态，包含两部分：

- **位姿**：每帧一行，外加基准坐标标签和外参
- **约束**：每条边的两端和测量值

约束必须一起存。存档的意义是"不用重跑"，而约束只在优化时才被算出来——不存的话，想画一次
约束图就得把几小时的配准全部重做，与存档的初衷直接矛盾。

两者的两端都**按点云文件路径记录，不用整数下标**。帧集一变（换了范围、丢了几帧），下标
就会静默错位，而按路径匹配 + 要求 100% 覆盖，错位会当场暴露。

复用一个 session 的存档要同时满足三条：文件读得出来、基准坐标一致、帧集按路径 100% 命中。
差一帧就当待优化重做，而不是用半套位姿。

## 5. 约束从哪来，权重怎么定

四类约束，各有各的精度，所以各有各的权重：

| 来源 | 测量什么 | 典型精度 |
|---|---|---|
| 窗口内帧间 | 相邻几米、同向、高重叠的两帧之间的相对位姿 | **0.035 m** |
| 同 session 回环 | 跨几百米弧长的重访 | 比上面差，需单独标定 |
| 跨 session | 新帧配到已有地图拼的 target 上 | **0.09 m** |
| INS 先验 | 每个位姿一条绝对位置 + 重力姿态 | 0.15 m 量级 |

权重是 **1/σ²**，实现上把 1/σ 乘进残差。三件事值得强调：

**σ 必须是那类测量的真实离散度，不是"我希望它多重要"。** 标定方法是看**白化残差的
rms**：残差除以假定的 σ 之后，若这个 σ 是对的，rms 应当 ≈ 1。rms = 0.13 意味着实际残差
比假设的小 7.7 倍，即权重给轻了。

**但只能标定测量项，不能标定先验项。** 一条帧间约束牵两个位姿，几千条约束共享几千个
参数，冗余度高，残差 rms 近似无偏。而 INS 先验是每个位姿一条，残差数 = 参数数，冗余度
≈ 0——它的残差小不是因为 INS 准，而是因为先验本身就是把位姿按住的那个东西，拿它自己的
残差定它自己的方差是自证。实测强行这么做会一路收紧到把位姿钉死，跨 session 约束完全失效。

**rms ≈ 1 也不等于几何正确。** 它只说明"残差与假设的噪声模型自洽"，而系统性偏差
（比如所有边都错同一个方向）会被模型一起吸收掉。所以最终判据始终是点云本身的重影，
不是残差统计。

还有一条容易忽略的：**同一次配准派生出的多条边不是独立测量**。它们共享同一个配准噪声，
如果各自按独立测量加权，等于把那一次测量的权重算了 N 遍。正确做法是各自的 σ 乘 √N。

## 6. 怎么判断结果对不对

**最近邻距离（nn）只用地面以上的点。** 全部点的最近邻会被路面主导，而路面点沿着平面
滑动几乎不产生距离变化——对横向错位近乎全盲，实测低估约一倍。

**必须加覆盖门。** 一帧的量程比局部 target 大得多，超出 target 覆盖范围的源点找不到
最近邻，会被记成搜索上限，直接把中位数抬起来。做法是记下 target 的占据格，只统计落在
占据格里的源点。不加这道门会把覆盖差异算成错位。

**配准的 inlier 比例量的是覆盖，不是精度。** 两块点云错开半米但大面积重叠时，inlier
可以很高。所以采纳判据里必须有一个真正量对齐的数（nn），不能只看 inlier。

**target 自身重影是天花板**（见第 3 节）。每次拼完 target 都要量，配准后的 nn 若明显
小于它，那个"更好"的数字是假的。

**约束的分布比数量重要。** "建成 N 条跨 session 约束"完全看不出这 N 条是均匀铺在全程，
还是挤在两三个路口。后者意味着中间路段没有任何约束把两趟绑在一起，一致性没有保证。
所以要把位姿图画出来看，而不是只看计数。

## 7. 几个关键取舍

**平面压制。** 平坦道路上激光在垂直方向是退化的（地面是一个大平面，竖直方向的最近邻
代价很平），配准出的 z / roll / pitch 噪声大；而 INS 的 roll/pitch 来自重力对齐，长期
无漂移。所以只采纳配准给出的 x / y / yaw，把另外三个自由度交还给 INS。

**动态物体必须剔除。** 一帧的采集时间里，行驶中的车会移动好几米。不剔的话 target 里
全是车的残影，而那不是位姿误差——配准修不掉，也不该去修。剔除必须在体素滤波**之前**做，
否则滤波会把车上的点和背景点平均进同一个格子，之后再删只剩被污染的格心。

**回环不判航向。** 曾经用"同向"和"反向"两个门收候选，中间留出的死区恰好吃掉十字路口的
垂直经过——而那正是最需要约束的地方。去掉航向门后统一用较宽松的阈值，实测那些原本被
死区排除的边配准质量与反向边相当。

**约束去重要看两端。** 同一地点重复建的边是冗余，但判据不能用"两端的中点"——两个几何上
完全不同的帧对可能共享中点。必须**两端都近**才算重复，否则会错杀同一地点的不同重访。

**加大跨 session 约束的权重没有用。** 实测把它的 σ 从 0.09 缩到 0.008（权重放大 126 倍），
session 间的一致性纹丝不动。原因是 0.09 已经是这类测量的真实精度，调权重不会让配准结果
本身变准，只会让图去更用力地满足一个本来就有噪声的测量。要改善一致性得从**约束的数量和
分布**入手。

## 8. 输入与输出

**输入**：多个 session 的点云、INS 位姿、相机标定与图像、雷达外参。

**输出**：

- 优化后的位姿（存档，也是下一轮增量的输入）
- 位姿图文件（全部顶点 + 全部约束 + 先验），可交给通用图优化工具复核
- 约束分布图（哪些位置有跨 session 约束、质量如何）
- 拼接好的点云（纯几何的一份用于量重影，另有上色和绝对坐标的版本）
- 可选：把优化后的位姿写回原始数据目录的一个新建平级目录

## 9. 这套方法的边界

- **配准修不了视角差异**。两趟只是穿过同一片区域而没走同一条路时（比如相距十几米、
  航向差 90°），量出来的"错位"里混着遮挡、可见面、采样密度的差异，那不是位姿误差。
- **相机上色在掠射的地面上不可用**。地面点在相机里是掠射的，一个像素的图像误差在
  地面上会被放大到几十厘米——标定再准也没用。同一块地面用雷达强度渲染则边缘锐利，
  说明几何是对的，糊在上色这一步。
- **重影的定位尚未完成**。目前所有测量都指向"问题不在位姿图"：去掉回环反而更差、
  增加跨 session 约束只让位姿动了几厘米、颜色与强度的互相关为零。见 README §6。
